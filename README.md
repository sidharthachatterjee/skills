# Skills

My agent skills. Small, composable, and written for my own workflow.

Each skill is a folder under `skills/` containing a `SKILL.md`, plus any reference files it points to.

## Install

Link every skill into `~/.agents/skills`, where OpenCode and other Agent Skills-compatible harnesses discover them:

```bash
scripts/link-skills.sh
```

Each entry is a symlink into this repo, so `git pull` keeps installed skills current. Re-run the script after adding, renaming, or removing a skill. Restart OpenCode to pick up changes.
